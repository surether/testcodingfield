# Subject Line Typing

교과 용어 데이터를 업로드하면 **단원(line)을 노선**, **용어(term)를 정거장**으로 바꾸어 진행하는 웹 타이핑 게임입니다.

> 이 프로젝트는 노선 진행형 타이핑 게임의 아이디어를 참고해 독립적으로 구현한 교육용 앱입니다. Metrotyping의 소스코드, 로고, 상표, 그래픽 자산은 포함하지 않습니다.

## 기능

- CSV / JSON 교과 데이터 업로드
- 한 파일에서 여러 단원(line) 자동 분리
- 타이핑 모드: 용어를 보고 그대로 입력
- 암기 모드: hint를 보고 term 입력
- 정방향 / 역방향 / 무작위 진행
- 실시간 CPM(분당 문자 수), 정확도, 오타, 시간 표시
- 노선형 진행 상황 표시
- 최근 20개 기록을 브라우저 localStorage에 저장
- 앱 안에서 CSV 입력 양식 다운로드
- 서버 없이 정적 호스팅 가능

## CSV 양식

```csv
subject,line,order,term,hint
과학,물질의 구성,1,원소,더 이상 다른 물질로 분해되지 않는 기본 성분
과학,물질의 구성,2,원자,물질을 구성하는 기본 입자
```

### 열 정의

| 열 | 필수 | 설명 |
|---|---|---|
| `subject` | 선택 | 교과명 |
| `line` | 필수 | 단원/세트명. 하나의 노선으로 표시 |
| `order` | 필수 | 해당 노선에서 용어 순서 |
| `term` | 필수 | 실제 타이핑 정답 |
| `hint` | 선택 | 설명 또는 암기 모드 문제 문장 |

CSV는 UTF-8 인코딩을 권장합니다. Excel에서 저장할 때 `CSV UTF-8(쉼표로 분리)`를 사용하면 한글 깨짐을 줄일 수 있습니다.

## JSON 형식

```json
[
  {"subject":"과학","line":"물질의 구성","order":1,"term":"원소","hint":"기본 성분"}
]
```
